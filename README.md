# Roommate Splitter

Roommate Splitter is a React + TypeScript app for organizing shared household expenses between roommates.

The project is intended to demonstrate frontend state management, form handling, and practical calculation logic in a real-world budgeting scenario.

---

## Features

- Create a roommate group
- Add roommates to a group
- Track shared household expenses
- Calculate how costs should be split
- Present a clean interface for managing shared payments

---

## Tech Stack

- React
- TypeScript
- Vite
- CSS / Tailwind-style utility classes

---

## Current Status

The project currently supports group creation and roommate management.

Planned improvements include:
- Expense entry
- Split calculations
- Settlement recommendations
- Local storage persistence
- Improved UI polish
